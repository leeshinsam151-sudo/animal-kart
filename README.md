# 🐼 Animal Kart — Three.js 멀티플레이 카트 레이싱

동물 캐릭터가 카트를 타고 달리는 브라우저 멀티플레이 레이싱 게임.
Three.js(렌더링) + Node.js/WebSocket(멀티플레이).
외부 3D 모델/이미지/사운드 파일 없이 모든 에셋(모델·텍스처·효과음·배경음악)을 코드로 생성합니다.

## 실행

```bash
npm install
npm start        # http://localhost:3000
```

- **멀티플레이 입장**: 같은 방 코드로 들어온 사람끼리 레이스 (최대 6명). 혼자 테스트하려면 브라우저 탭을 두 개 열어도 됩니다.
- **🤖 AI 봇과 연습하기**: 서버 없이 브라우저 안에서 AI 봇 5명과 6인 레이스. 봇도 드리프트하고 아이템을 씁니다. 서버에 접속할 수 없으면 자동으로 이 모드로 전환됩니다.

친구와 같이 하려면 같은 와이파이에서 `http://<내 PC IP>:3000/?room=방이름` 으로 접속하거나,
Render / Railway / Fly.io 등 Node 호스팅에 올리면 됩니다 (WebSocket 지원 필요, `PORT` 환경변수 사용).

서버 없이 AI 연습 모드만 정적 호스팅(GitHub Pages 등)에 올리려면:

```bash
npm run build:static   # dist/ 생성 → 아무 정적 서버로 열기 (예: npx serve dist)
```

## 조작

## 트랙 6개 (로비에서 방장이 선택)

| 트랙 | 길이 · 바퀴 | 특징 |
|---|---|---|
| 🌲 숲 계곡 | 1.9km · 3바퀴 | S자 숲길, 언덕 점프 → 계곡 내리막, 움푹 꺼진 곳 → 언덕 점프 |
| ❄️ 빙하 능선 | 2.1km · 3바퀴 | 부스터 발판 + **대점프**(약 90m, 부스터 시 약 116m) → 얼음 동굴(330m) → 얼음 언덕 점프, 노면이 미끄러움 (그립 55%) |
| 🏜️ 모래 언덕 | 1.8km · 3바퀴 | 모래 언덕 3개 + 점프대, 작은 물결이 이어지는 리듬 구간, 모래밭은 크게 감속 |
| 🏙️ 고가도로 | 1.9km · 3바퀴 | 지하차도로 내려갔다가 15m 고가도로(약 1.2km), 끝에서 점프 |
| 🧱 블록 세상 | 2.0km · 3바퀴 | 장난감 벽돌 탑·블록 나무, 큰 언덕 점프, **12m 낭떠러지** |
| 🌍 대륙 횡단 | 5.6km · 2바퀴 | 다섯 테마를 모두 지나는 긴 코스 (구역 경계마다 게이트·배너, 하늘색이 구역에 따라 바뀜) |

- 트랙 정의(모양·테마·바퀴 수)는 `public/js/tracks.js` 한 곳에 있고 서버와 브라우저가 같이 씀
- **기울어진 커브(뱅크)**: 급한 커브일수록 안쪽으로 최대 약 5° 기울어지고 카트도 같이 기움
- 오르막에선 느려지고 내리막에선 빨라짐. 점프대·급한 언덕 꼭대기에서 공중에 뜨고, 공중에선 조향/가속이 약해짐
- 점프대는 가장 곧은 구간에 배치 (착지하자마자 벽에 부딪히지 않게)
- 자동주행 기준 랩타임 약 40초 (테마 트랙), 3바퀴 레이스 약 2분
- **6인 기준**: 도로 폭 20m, 출발 그리드 3열 × 2줄, 아이템 박스 한 줄 6개

## 아이템

- 트랙에 약 380m 간격으로 **아이템 박스** 줄(6개씩)이 있음. 깨면 룰렛 후 아이템 획득, **최대 2개 보관** (Z 를 누르면 첫 칸부터 사용, 박스는 4초 뒤 재생성)
- 🍌 **바나나**: 내 뒤에 설치. 밟은 카트는 1.2초간 빙글빙글 돌며 감속
- 💧 **물폭탄**: 약 85m 앞으로 포물선 투척. 착지 지점 반경 7.5m 안의 카트는 1.8초간 물방울에 갇힘 (던진 사람은 면역)
- 🚀 **미사일**: 220m 이내의 바로 앞 순위 카트를 자동 추적 (95m/s, 최대 480m 비행). 220m 보다 멀면 직진 발사. 맞으면 폭발과 함께 공중에서 한 바퀴 돌고 1.5초간 거의 정지. **막는 법**: 바나나를 뒤에 두기, 점프대에서 뜨기(미사일은 낮게 날아감), 부스터로 도망가기. 노림당하는 사람에게는 경고 + 빨간 화면 + 경고음
- ⚡ **게이지 충전**: 드리프트 부스터 게이지를 즉시 가득 채움 → 부스터 1개 획득 (Space 로 사용). 부스터 2칸이 꽉 찼으면 게이지만 가득 찬 채로 있다가 부스터를 쓰면 바로 채워짐
- 🛡️ **방어막**: 5초 동안 미사일·물폭탄·바나나·번개를 **한 번** 막아줌 (상대 화면에도 금빛 방울이 보임)
- 🧲 **자석**: 200m 안의 바로 앞 카트에게 3초 동안 끌려감 (최고속도 68), 그대로 들이받으면 상대가 튕겨나감
- ⛈️ **번개 구름**: 1등(내가 1등이면 2등) 머리 위에 5초 뒤 번개 → 스핀. 다른 카트에 부딪히면 구름이 그 사람에게 넘어감 (서버가 주인과 시각 결정)
- 순위에 따라 확률이 달라짐

  | 순위 | 🍌 | 💧 | 🚀 | ⚡ | 🛡️ | 🧲 | ⛈️ |
  |---|---|---|---|---|---|---|---|
  | 1등 | 40% | 20% | 0% | 15% | 25% | 0% | 0% |
  | 중간 | 17% | 17% | 18% | 12% | 12% | 12% | 12% |
  | 꼴등 | 6% | 12% | 22% | 14% | 8% | 20% | 18% |

### 연결 안정성 (여러 명 플레이)
- **재접속**: 연결이 끊기면 자동으로 최대 5번 재접속. 레이스 중이면 서버가 20초 동안 자리를 남겨둬서 **같은 자리에서 이어서** 달림 (놓친 바나나·완주 순위도 다시 받음)
- **유령 플레이어 방지**: 서버 5초 하트비트 + 클라이언트 핑. 와이파이가 조용히 끊겨도 약 10초 안에 감지
- **방장 이전**: 방장이 나가거나 끊기면 연결된 사람에게 즉시 넘김
- **부드러운 상대 카트**: 서버 시각 기준 보간 + 회선 흔들림에 맞춘 지연 자동 조절(100~450ms) + 짧은 예측 이동 + 튐 보정. HUD 에 핑 표시
- **관전**: 레이스 중 들어온 사람은 현재 상태(깔린 바나나 등)를 받아서 관전
- **카트끼리 충돌**: 상대 카트를 회전 속도까지 반영한 곡선 예측으로 "지금 실제 위치"에 그리고, 같은 위치로 충돌 판정 (보이는 곳 = 부딪히는 곳)
  - 박은 쪽이 서버를 거쳐 박힌 쪽에 '부딪힘' 알림 → 상대 화면이 렉으로 충돌을 놓쳐도 양쪽 모두 튕김 (같은 충돌이 두 번 적용되지 않게 300ms 중복 방지)
  - 높이 차 1.6m 이상(점프 중)이면 서로 통과, 반발 계수 0.6 (`physics.js`의 `BUMP_K`)
  - 충돌 시 불꽃 + 쿵 소리, 벽 충돌·착지에도 소리

```bash
npm test   # 보간·예측 단위 테스트(4가지 네트워크 조건) + 카트 충돌 단위 테스트
```

### 네트워크 방식
- **클라이언트 권한 이동**: 각자 자기 차를 시뮬레이션하고 50ms마다 위치를 서버로 전송.
- 서버는 방 단위로 모아 20Hz 스냅샷을 브로드캐스트, 다른 차는 **110ms 지연 보간**으로 부드럽게 표시.
- 순위 = 진행도(랩 + 트랙 위 위치). 완주/결과는 서버가 판정 (진행도·최소 랩타임 검사).
- 레이스 중 들어온 사람은 관전 후 다음 판부터 참가.

### 커스터마이즈 포인트
- 트랙 모양·바퀴 수: `tracks.js`의 `TRACKS` (첫 점이 출발선, `len` 은 실제 길이와 맞춰야 함)
- 높낮이·점프대·동굴·고가도로: `track.js`의 `buildProfile()`
- 구역 색/언덕 높이/그립/하늘: `track.js`의 `ZONES`
- 아이템 박스 간격, 물폭탄 사거리·범위, 미사일 속도·수명: `track.js`의 `itemBoxPositions()`, `items.js` 상단 상수
- 아이템 확률: `main.js`의 `ITEM_ODDS`
- 최대 인원: `server.js`의 `MAX_PLAYERS` (테스트용으로 `LAPS=1 npm start` 하면 모든 트랙 1바퀴)
- 카트 성능: `physics.js` 상단 상수 (`MAX_SPEED`, `BOOST_MAX`, `GAUGE_RATE` 등)
- 캐릭터 추가: `kart.js`의 `CHARACTERS` 에 항목 추가 + `server.js`의 `CHARACTERS` 목록에 id 추가
- 카트 디자인: `kart.js`의 `createKart()`

예) 빙하 구역으로 순간이동: `const {game,track}=__dbg; const i=track.zone.indexOf(1); game.local.ctrl.reset(track.points[i].x, track.points[i].z, 0)`
